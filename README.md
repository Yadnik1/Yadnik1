<td valign="top" width="62%">

I build the whole device, not just one layer of it: schematic capture, PCB
layout in KiCad, board bring-up, then the firmware and the cloud telemetry that
makes the data useful. Most of my work lives on ARM Cortex-M (STM32), with
ESP32, RP2040 and Nordic parts in the mix.

- Building production **STM32U5** firmware for multi-spectral imaging, plus a 4G-LTE asset tracker
- Comfortable from **register-level bare-metal** up to **RTOS** schedulers and OTA update flows
- **Google Summer of Code 2021** contributor on **Zephyr RTOS** (BeagleConnect Freedom)
- Currently picking up **embedded Rust** and going deeper on low-power, safety-critical design
- Reach me about ARM Cortex-M, RTOS internals, sensor drivers, and getting data off a device reliably
